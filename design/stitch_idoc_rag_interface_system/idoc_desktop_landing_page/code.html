FREQUENT QUESTIONS

Frequently Asked Questions

Everything you need to know about formats, privacy, and retrieval mechanics.

Which file types can I upload? +

iDoc natively supports PDF, DOCX, TXT, and Markdown files up to 20 MB per file. Text is parsed using structural headers and converted into high-fidelity sentence chunks for vector indexing.

Can I ask questions across multiple documents? +

Yes. You can query your entire indexed workspace at once for cross-document synthesis or isolate individual files using the integrated scope dropdown.

Does iDoc work with scanned PDFs? +

Scanned PDFs require searchable text layers. Native text PDFs are processed with high accuracy; optical character recognition (OCR) for pure image-only scans is not currently included.

Where are my documents processed? +

Document processing depends on your configured Python API and model target. You can configure local embeddings and self-hosted models or connect directly to OpenAI API keys for cloud inference like GPT-4o.
